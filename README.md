# Лабораторна робота: автоматичне укладання частотних словників (ЧС)

Програма будує частотні словники (словоформ, лем, частин мови) для двох вибірок українських текстів: публіцистичної й художньої. Кожну вибірку ділить на 20 підвибірок по 1000 слововживань. Результат зберігається в SQLite, а статистика обчислюється агрегуючими SQL-запитами.

## Структура репозиторію

| Файл / папка | Призначення |
|---|---|
| `chs.py` | уся програма |
| `requirements.txt` | залежності |
| `texts3/second.txt` | вибірка 1: Іван Дзюба, «Інтернаціоналізм чи русифікація?» |
| `texts3/vynnychenko.txt` | вибірка 2: Володимир Винниченко, «Записки Кирпатого Мефістофеля» |
| `data/freq3.db` | база даних (SQLite), створюється при запуску |
| `report3.md` | звіт зі статистикою, створюється при запуску |

## Встановлення

```
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

Потрібні `pymorphy3`, `pymorphy3-dicts-uk`, `tokenize-uk`, `scikit-learn`. Старий `pymorphy2` не працює з Python 3.11 і новішими, тому в коді використано `pymorphy3` (якщо його немає, скрипт спробує `pymorphy2`).

## Запуск

```
python chs.py
```

Тексти, назви вибірок, жанри, шляхи до бази й звіту за замовчуванням задані в `chs.py`. Їх можна змінити аргументами командного рядка (`--texts`, `--names`, `--genres`, `--db`, `--report`, `--size`).

## I. Вступна частина

### 1.1 Лінгвістична однорідність вибірок

| | Вибірка 1 | Вибірка 2 |
|---|---|---|
| Автор, твір | І. Дзюба, «Інтернаціоналізм чи русифікація?» (1965) | В. Винниченко, «Записки Кирпатого Мефістофеля» |
| Жанр | публіцистика (есеїстика, політична критика) | художня проза |
| Стиль | публіцистичний, аргументативний, з цитатами й посиланнями | художній, з описовими й діалоговими фрагментами |
| Всього слів у тексті | 87 327 | 71 028 |

Кожна вибірка однорідна за автором, жанром і стилем. Між собою вони контрастні, що дозволяє порівняти частотні характеристики двох жанрів.

Зауваження: початок тексту Дзюби містить титульну сторінку, зміст і переднє слово. Вони входять до перших 20 000 слів вибірки.

### 1.2 Статистична однорідність вибірок

- **Метод організації вибірки:** механічний, перші 20 000 слововживань кожного тексту.
- **Обсяг вибірки:** 20 000 слововживань.
- **Кількість підвибірок:** 20, по 1000 слововживань (послідовні блоки).
- **Достатність обсягу.** Для кожної частини мови обчислено відносну похибку частоти з довірчою ймовірністю 95 %: δ = 1,96·√((1−p)/(N·p)), де p частка класу, N = 20 000. Повні таблиці наведено в `report3.md`.
- **Однорідність підвибірок.** Для кожної частини мови обчислено коефіцієнт варіації частот по 20 підвибірках (колонка «V» у звіті).

## II. Основна частина: укладання ЧС

### 2.1 Обробка тексту

1. **Токенізація:** `tokenize_uk.tokenize_words`. Залишаються лише слова з кирилицею, у нижньому регістрі. Повтори слів не відкидаються, кожне слововживання зберігається окремо.
2. **Лематизація й частиномовні теги:** `pymorphy3` (словник `uk`), береться перший розбір `parse()[0]`.
3. **Звуження тегів** до позначень із методичних рекомендацій:

| Теги pymorphy | Позначення |
|---|---|
| NOUN | noun |
| VERB, INFN | verb |
| ADJF, ADJS, PRTF, PRTS | adj |
| ADVB | adv |
| CONJ | conj |
| PREP | prep |
| PRCL | part |
| INTJ | intj |
| NUMR | numr |
| GRND | advp |
| NPRO | npro |
| PRED, COMP | pred, comp |
| тег не визначено | unkn |

4. **Поділ вибірки** на 20 підвибірок по 1000 слововживань: номер підвибірки = (позиція слова − 1) // 1000 + 1.

### 2.2 Структура бази даних (`data/freq3.db`)

| Таблиця | Зміст |
|---|---|
| `samples` | опис вибірок: назва, джерело, жанр, обсяг |
| `tokens` | кожне слововживання окремим рядком: вибірка, позиція, номер підвибірки, словоформа, лема, частина мови |
| `freq_wordform` | **БД_ЧС_словоформ**: словоформа, лема, частина мови, абсолютна частота, `part_1`…`part_20` |
| `freq_lemma` | **БД_ЧС_лем**: лема, абсолютна частота, `part_1`…`part_20` |
| `freq_pos` | **БД_ЧС_ЧМ**: частина мови (латинська й українська назви), абсолютна частота, `part_1`…`part_20` |

Усі три словники отримано з таблиці `tokens` агрегуючими запитами:

```sql
INSERT INTO freq_pos(sample_id, pos, abs_freq, part_1, ..., part_20)
SELECT sample_id, pos, COUNT(*),
       SUM(CASE WHEN part_no = 1 THEN 1 ELSE 0 END), ...,
       SUM(CASE WHEN part_no = 20 THEN 1 ELSE 0 END)
FROM tokens
GROUP BY sample_id, pos;
```

Аналогічно будуються `freq_wordform` (групування за словоформою) і `freq_lemma` (за лемою).

### 2.3 Додаткова статистика

Для кожної вибірки у `report3.md` обчислюються:

- кількість слововживань, різних словоформ і різних лем;
- TTR (type/token ratio) для словоформ і лем;
- кількість гапаксів (слів, що трапляються один раз);
- середня довжина слова;
- топ-20 найчастотніших лем;
- відносна похибка та коефіцієнт варіації для частин мови;
- **TF-IDF** по лемах: документом вважається підвибірка (разом 40 документів).

### 2.4 Приклади SQL-запитів

```sql
-- частини мови у вибірці 1
SELECT pos, SUM(abs_freq) AS n FROM freq_pos
WHERE sample_id = 1 GROUP BY pos ORDER BY n DESC;

-- порівняння двох вибірок за частинами мови
SELECT s.name, t.pos, COUNT(*) AS n
FROM tokens t JOIN samples s USING (sample_id)
GROUP BY s.name, t.pos ORDER BY s.name, n DESC;

-- 10 найчастіших лем у підвибірці 5 вибірки 1
SELECT lemma, COUNT(*) AS n FROM tokens
WHERE sample_id = 1 AND part_no = 5
GROUP BY lemma ORDER BY n DESC LIMIT 10;
```

### 2.5 Результати

Таблиці частин мови, загальна статистика, топ лем і TF-IDF для обох вибірок наведено у `report3.md`.

## Обмеження

- Береться перший розбір `parse()[0]` без зняття морфологічної омонімії, тому частина лем і тегів може бути неточною.
- Слова, яких немає у словнику (власні назви, сленг, оказіоналізми), отримують тег `unkn` або лему, запропоновану словником.
- Початок тексту Дзюби містить титульні сторінки й зміст, які входять до вибірки.
- Для перевірки лематизації можна звірятися зі словником ВЕСУМ (https://r2u.org.ua/vesum/).
